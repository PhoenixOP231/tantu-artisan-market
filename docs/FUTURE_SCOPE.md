# Future scope

1. **Evidence-based provenance:** artisan identity checks, uploaded certification evidence, admin audit trail and third-party craft bodies. Keep the passport trust label explicit at each stage.
2. **Real demand data:** consented orders and enquiries, regional seasonality and verified festival calendars. Evaluate forecasting error before issuing production advice.
3. **Speech reliability:** native or on-device speech models for Marathi and Hindi so dictation works without network or browser service support.
4. **Catalogue quality:** evaluate model suggestions against artisan-reviewed examples; add more Indian language and craft vocabularies. Do not auto-publish uncertain fields.
5. **Production commerce:** payment provider, shipping quotes, returns, GST/tax handling, multi-item orders and buyer dispute process.
6. **Scale:** move photo storage to object storage and SQLite to a managed database when concurrent writes or multi-instance deployment warrants it.

These are future work, not capabilities claimed by the current demo.
